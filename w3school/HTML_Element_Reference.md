# HTML 태그 정리 (HTML Element Reference)

수업 자료 *HTML Element Reference* (W3Schools 기준) 를 용도별로 묶어 한국어로 정리했다.
마지막 표는 HTML5 에서 **더 이상 쓰지 않는 태그** 와 대신 쓸 것.

---

## 문서 구조 · 메타데이터

| 태그 | 설명 |
|------|------|
| `<!DOCTYPE>` | 문서 형식 선언 (HTML5 는 `<!DOCTYPE html>`) |
| `<html>` | HTML 문서의 최상위 요소 |
| `<head>` | 문서 정보(메타데이터)를 담는 영역 |
| `<title>` | 브라우저 탭에 보이는 문서 제목 |
| `<meta>` | 문자 인코딩, 뷰포트 등 문서 정보 |
| `<link>` | 외부 리소스 연결 (주로 CSS 파일) |
| `<style>` | 문서 안에 CSS 작성 |
| `<script>` | 자바스크립트 작성 또는 연결 |
| `<noscript>` | 스크립트를 쓸 수 없을 때 보여 줄 내용 |
| `<base>` | 상대 경로의 기준 URL 지정 |
| `<body>` | 화면에 보이는 본문 |
| `<!--...-->` | 주석 |

## 시맨틱 레이아웃

| 태그 | 설명 |
|------|------|
| `<header>` | 문서나 구역의 머리말 |
| `<nav>` | 내비게이션 링크 묶음 |
| `<main>` | 문서의 핵심 내용 (한 번만) |
| `<section>` | 주제별 구역 |
| `<article>` | 독립적인 글 (블로그 글, 뉴스 기사) |
| `<aside>` | 본문 옆 부가 내용 (사이드바) |
| `<footer>` | 문서나 구역의 꼬리말 |
| `<hgroup>` | 제목과 부제목 묶음 |
| `<search>` | 검색 영역 |
| `<address>` | 작성자 연락처 |
| `<div>` | 의미 없는 블록 묶음 |
| `<span>` | 의미 없는 인라인 묶음 |

## 제목 · 텍스트

| 태그 | 설명 |
|------|------|
| `<h1>` ~ `<h6>` | 제목 (숫자가 작을수록 큼) |
| `<p>` | 단락 |
| `<br>` | 줄바꿈 |
| `<hr>` | 주제가 바뀌는 구분선 |
| `<pre>` | 공백·줄바꿈을 그대로 보여 주는 텍스트 |
| `<blockquote>` | 다른 출처에서 인용한 긴 글 |
| `<wbr>` | 필요하면 줄바꿈해도 되는 위치 |

## 텍스트 꾸미기 · 의미

| 태그 | 설명 |
|------|------|
| `<strong>` | 중요한 텍스트 (굵게) |
| `<b>` | 굵은 텍스트 (의미 없이 모양만) |
| `<em>` | 강조 (기울임) |
| `<i>` | 다른 어조의 텍스트 (기울임) |
| `<mark>` | 형광펜 하이라이트 |
| `<small>` | 작은 글씨 (주석, 저작권 표시) |
| `<sub>` / `<sup>` | 아래 첨자 / 위 첨자 (H₂O, x²) |
| `<del>` / `<ins>` | 삭제된 / 추가된 텍스트 |
| `<s>` | 더 이상 맞지 않는 텍스트 (취소선) |
| `<u>` | 밑줄로 구분한 텍스트 |
| `<abbr>` | 약어 (`title` 에 전체 이름) |
| `<cite>` | 작품 제목 |
| `<dfn>` | 정의하는 용어 |
| `<code>` | 컴퓨터 코드 |
| `<kbd>` | 키보드 입력 |
| `<samp>` | 프로그램 출력 예시 |
| `<var>` | 변수 |
| `<time>` | 날짜 · 시간 |
| `<data>` | 기계가 읽을 값 연결 |
| `<bdi>` / `<bdo>` | 글자 방향 분리 / 강제 지정 |
| `<ruby>` `<rt>` `<rp>` | 한자 위 읽는 법 같은 루비 주석 |

## 링크 · 목록

| 태그 | 설명 |
|------|------|
| `<a>` | 하이퍼링크 |
| `<ul>` | 순서 없는 목록 |
| `<ol>` | 순서 있는 목록 |
| `<li>` | 목록 항목 |
| `<menu>` | 순서 없는 목록 (`<ul>` 과 같음) |
| `<dl>` | 설명 목록 |
| `<dt>` | 설명 목록의 용어 |
| `<dd>` | 설명 목록의 설명 |

## 이미지 · 미디어

| 태그 | 설명 |
|------|------|
| `<img>` | 이미지 |
| `<picture>` | 상황별로 다른 이미지를 고르는 묶음 |
| `<figure>` | 그림·도표 같은 독립 콘텐츠 |
| `<figcaption>` | `<figure>` 의 설명 |
| `<map>` / `<area>` | 이미지 맵 / 클릭 영역 |
| `<audio>` | 소리 |
| `<video>` | 동영상 |
| `<source>` | `<audio>` · `<video>` 의 파일 후보 |
| `<track>` | 자막 파일 |
| `<iframe>` | 다른 페이지를 안에 넣는 창 |
| `<embed>` | 외부 콘텐츠 넣기 |
| `<object>` / `<param>` | 외부 콘텐츠 / 그 설정값 |
| `<canvas>` | 자바스크립트로 그림 그리는 영역 |
| `<svg>` | SVG 벡터 그래픽 |

## 표

| 태그 | 설명 |
|------|------|
| `<table>` | 표 |
| `<caption>` | 표 제목 |
| `<thead>` / `<tbody>` / `<tfoot>` | 표의 머리 / 본문 / 꼬리 묶음 |

| `<textarea>` | 여러 줄 입력 칸 |
| `<button>` | 버튼 |
| `<select>` | 드롭다운 목록 |
| `<option>` | 드롭다운 항목 |
| `<optgroup>` | 드롭다운 항목 묶음 |
| `<datalist>` | 입력 칸의 자동 완성 후보 |
| `<fieldset>` / `<legend>` | 관련 입력 묶음 / 그 제목 |
| `<output>` | 계산 결과 |
| `<meter>` | 범위 안의 값 (게이지) |

## 상호작용 · 기타

| 태그 | 설명 |
|------|------|

## HTML5 에서 쓰지 않는 태그

| 태그 | 용도 | 대신 쓸 것 |
|------|------|------------|
| `<acronym>` | 두문자어 | `<abbr>` |
| `<applet>` | 자바 애플릿 | `<embed>`, `<object>` |
| `<basefont>` | 문서 기본 글꼴 | CSS |
| `<big>` | 큰 글씨 | CSS |
| `<center>` | 가운데 정렬 | CSS |
| `<dir>` | 디렉터리 목록 | `<ul>` |
| `<font>` | 글꼴 · 색 · 크기 | CSS |
| `<frame>` / `<frameset>` / `<noframes>` | 프레임 | `<iframe>` 또는 CSS 레이아웃 |
| `<strike>` | 취소선 | `<del>`, `<s>` |
| `<tt>` | 고정폭 글씨 | CSS (`font-family: monospace`) 또는 `<code>` |
